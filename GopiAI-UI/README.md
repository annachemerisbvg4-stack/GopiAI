# 🤖 GopiAI - Веб-интерфейс для Google Gemini

Современный веб-интерфейс для работы с Google Gemini AI через удобный чат-интерфейс.

## ✨ Возможности

- 💬 **Чат-интерфейс** - Удобное общение с Gemini AI
- 🎯 **Выбор модели** - Поддержка различных моделей Gemini (Pro, 1.5 Pro, 1.5 Flash)
- 🌐 **Веб-интерфейс** - Работа через браузер без установки дополнительного ПО
- 🚀 **Быстрый запуск** - Простая настройка и запуск
- 🔧 **API интеграция** - Прямая интеграция с Google Generative AI API

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Настройка API ключа

1. Получите API ключ от Google: https://makersuite.google.com/app/apikey
2. Создайте файл `.env` на основе `.env.example`:

```bash
cp .env.example .env
```

3. Добавьте ваш API ключ в файл `.env`:

```env
GEMINI_API_KEY=your_actual_api_key_here
```

### 3. Запуск приложения

#### Обычный режим (с настоящим API ключом):
```bash
python run.py
```

#### Демо-режим (для тестирования интерфейса):
```bash
python demo_app.py
```

### 4. Открытие в браузере

Перейдите по адресу: http://localhost:12001

## 🔧 API Endpoints

- `GET /` - Главная страница с веб-интерфейсом
- `GET /api` - Информация об API
- `GET /health` - Проверка состояния сервера
- `POST /api/gemini/generate` - Генерация текста
- `POST /api/gemini/chat` - Чат с AI
- `GET /api/gemini/models` - Список доступных моделей

## ⚙️ Конфигурация

### Переменные окружения (.env файл):

```env
# Google Gemini API Key (обязательно)
GEMINI_API_KEY=your_api_key_here
GOOGLE_API_KEY=your_api_key_here  # альтернативное название

# Настройки сервера
PORT=12001                # Порт сервера
HOST=0.0.0.0             # Хост сервера
DEBUG=true               # Режим отладки

# Настройки логирования
LOG_LEVEL=INFO           # Уровень логирования
LOG_TO_FILE=true         # Сохранение логов в файл
```

## 🐛 Решение проблем

### Ошибка "API key not valid"
- Проверьте правильность API ключа в файле `.env`
- Убедитесь, что API ключ активен в Google AI Studio

### Ошибка "Port already in use"
- Измените порт в файле `.env`: `PORT=12002`
- Или остановите процесс, использующий порт: `lsof -ti:12001 | xargs kill`

### Проблемы с зависимостями
```bash
pip install --upgrade pip
pip install -r requirements.txt --force-reinstall
```

## 🔄 Режимы работы

### 1. Продакшн режим (app.py + run.py)
- Использует настоящий Gemini API
